# 竹林锦鲤池

用 three.js 绘制的一方池塘：清澈见底的池水微波荡漾，几尾金色锦鲤在水中游弋，池边是青翠的竹林、鹅卵石和花草。

## 运行

整个项目只有一个 `index.html`，three.js 从 jsDelivr CDN 加载。用任何静态服务器打开即可：

```sh
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 交互

- 拖动旋转视角，滚轮或双指缩放
- 轻点水面撒鱼食，锦鲤会游过来吃，水面泛起涟漪
- 点右下角“跟随锦鲤”，镜头跟着一条锦鲤，可以拉近看鱼头；再点一次回到池塘
- 点右下角“透视鱼骨”，看鱼身里的骨骼

## 实现要点

- 水面：自定义着色器。先把不含水面的场景渲染到带深度的纹理，再按水深做折射扭曲、光线吸收和菲涅尔反射，所以能看清池底
- 水波：多组正弦波叠加，加上投喂和锦鲤吻水时产生的扩散涟漪
- 池底：焦散光纹随时间流动
- 锦鲤：按成年锦鲤的比例建模。头长约为体长的 27%，头部比例按鲤鱼的形态测量数据：吻长约占头长的 40%，眼径约 15%，两眼间距约 40%；鳃盖后身体变宽，尾柄粗壮，尾鳍浅叉形
- 鱼头：厚唇向内翻成口腔，嘴略朝下；张口和噘嘴伸出用形变目标实现。鳃盖是一块半圆形骨板，绕前缘铰接，后缘离皮肤越远翘起越多，上下两端平滑地贴回皮肤，没有棱角；下面是挖空的鳃腔和四对沿鳃盖弧线排列的鲜红鳃弓鳃丝。呼吸时口和鳃盖交替开合，鳃盖张开时能看到红色的鳃。两对须（上唇一对短须、口角一对长须）由粗到细，随唇移动、随游速向后飘。另有鼻孔和鼻瓣、金色虹膜的眼睛、眼眶边缘、眼下的一串眶下骨、鳃盖前的前鳃盖骨、鳃盖上的放射纹、头部侧线管的感觉孔（眶上、眶下、前鳃盖-下颌、颞上）和细小的皮肤颗粒；头部皮肤比鳞片略哑光
- 鳞片：按鲤鱼的鳞片排布生成（侧线鳞约 36 枚、体周约 24 行，相邻行错开半枚形成斜行），每枚鳞片前缘埋入、后缘翘起，像屋瓦一样层层覆盖；由此生成法线贴图，让每枚鳞片单独反光，再加上侧线孔、鳃盖骨缘和一层光滑的黏液清漆
- 鱼骨：头骨刚性，其后是 19 节脊椎关节（每节代表鲤鱼约 36 枚椎骨中的两枚）和尾鳍中的 2 节。肋骨区的关节几乎不弯，越近尾部允许的弯曲越大，身体的摆动受这套骨骼约束。椎骨、肋骨、髓棘、脉棘、肌间刺、头骨、鳃盖、鳍基骨都建了模型，随身体一起弯曲；点右下角“透视鱼骨”可以看到
- 鳍：按鲤鱼的鳍条数建模（尾鳍 19 根主鳍条、背鳍约 20 根、胸鳍 16 根），鳍膜在鳍条之间折起；鳍条分节、末端分叉；背鳍和臀鳍前缘是硬棘
- 游动：沿身体传递的波，波长约一个体长，振幅向尾部按二次方增大，尾尖摆幅约 0.2 体长；会巡游、滑行、悬停、浮上水面吻水和抢食。巡游时胸鳍收拢，慢速时张开划水，转弯时内侧胸鳍张开制动
- 竹林、草、花：实例化网格，在顶点着色器里随风摇曳
